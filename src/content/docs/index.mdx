## Record your first session

```sh frame="terminal" title="Install and connect"
npm install -g @oqura/wisdom
cd your-project
wisdom connect
claude          # or codex, or pi: use it as usual
```

Then read what happened: the session at a glance, then any turn in full. Below is an example
session, written to show the format.

## What you get

- Prompts, replies, tool calls and file diffs, recorded as they happened. Nothing is summarized,
  and gaps in the recording are marked where they occur.
- One way to read Claude Code, Codex and Pi sessions: for you in the terminal or the dashboard,
  for your agents through a skill.
- Hooks that never block your agent. If the background service is down, events wait on disk.
- Everything stays in the project's `.wisdom/` folder until you choose to share it.

Start with the [quick start](/wisdom-docs/getting-started/quick-start/), or read
[how it works](/wisdom-docs/concepts/how-it-works/).
