Reading a session takes two moves: **glance** to see its shape, then **open** the part that
matters. Your agents use the same two moves, through their skill.

```sh
wisdom glance                          # every recorded session, newest first
wisdom glance latest                   # one session: its shape and every turn
wisdom open t2 --capture latest        # turn 2, whole
```

Name a session by its full ID, by its first 8 or more characters, or as `latest` (the newest
session with a turn). Every command finds `.wisdom/` from the folder you're in, like git
finds `.git`.

## Positions

Everything in a session has a short address. A glance shows them; `open` takes them.

![Glance, then open: wisdom glance latest lists a session's turns (t1, t2, t3), subagents (a1) and changes outside any turn. wisdom open t2 shows turn 2 in order: the prompt, each tool call, the reply and the diffs. wisdom open t2/c3 shows one call whole: its status, full input and full output.](../../../assets/session-positions.svg)

| Position | What it opens |
| --- | --- |
| `t3` | Turn 3: your third prompt and everything the agent did until it answered |
| `t3/c2` | The second tool call of turn 3, its full input and output |
| `a1` | The first subagent, laid out like a turn |
| `a1/c2` | A tool call of that subagent |
| `outside` | Calls and file changes outside any turn |

`p1`, `p2`… label the file changes inside a turn. They aren't addresses: open the turn or the
call to see them.

## In a terminal, or piped

In a terminal, `glance` and `open` are coloured and fitted to its width. A long prompt or
tool output is folded, and the fold names the command that shows it whole. No word is
changed.

Piped to a file or another program, or with `--plain`, you get the exact text your agents
read: uncoloured and unfolded.

```sh
wisdom open t2 --capture latest --plain > turn.txt
```

## Reading the labels

These labels say how much the record can tell you:

| Label | What it means |
| --- | --- |
| `observed during c1` | The file changed while that call ran. Timing, not proof the call made it. |
| `external-or-unknown` | The file changed while no tool was running: you, your editor, another process. |
| `thinking  redacted` | The agent thought, but its text wasn't recorded (Claude Code omits it; Codex encrypts it). |
| `not recorded` | A gap in the recording, with the reason. |
| `no result recorded` | The call never reported back. Not the same as success. |
| `ok` | The tool reported success. Not proof the code is right. |

<Aside title="Long answers">
One answer holds at most 80,000 characters. A longer one ends with
`limited · lines 1–1,950 of 41,230 · continue: {…}` and the exact way to get the rest: add
`--from` and `--at` as shown. `--at` pins the version, so a session that's still recording
can't change under you while you read.
</Aside>
