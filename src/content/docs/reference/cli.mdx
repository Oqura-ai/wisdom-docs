Every command finds `.wisdom/` from the current folder upward, the way git finds `.git`. On
Windows PowerShell with scripts blocked, type `wisdom.cmd`.

`<session>` is a session ID, its first 8 or more characters, or `latest`.
`<position>` is `t3` (a turn), `t3/c2` (a tool call), `a1` (a subagent), `a1/c2`, or `outside`.

## Set up a project

| Command | What it does |
| --- | --- |
| `wisdom connect` | Record plain `claude`, `codex` and `pi` started here, with your own login. Run again to repair. |
| `wisdom disconnect` | Take out exactly what `connect` added. Recordings are kept. |
| `wisdom init` | Set up `.wisdom/` and a home for each agent, for `wisdom track`. Run again to repair. |
| `wisdom doctor` | Check that everything works, and print the fix for each problem. |

## Run an agent

| Command | What it does |
| --- | --- |
| `wisdom track claude\|codex\|pi` | Start an agent with its home in this project, recording. |
| `wisdom resume <session-id>` | Continue a recorded session, still recording. Full ID only. |
| `wisdom handoff <claude\|codex\|pi\|session-id>` | Continue in a new or existing session that reads another session first. |

## Read a session

| Command | What it does |
| --- | --- |
| `wisdom glance` | List recorded sessions, newest first. |
| `wisdom glance <session>` | One session's shape and every turn. |
| `wisdom open <position> --capture <session>` | One turn, tool call or subagent, whole. |
| `wisdom glance --commit <commit>` | Which recorded steps made each piece of a commit (a hash, a branch or `HEAD`). |
| `wisdom dashboard` | Print the address of the live dashboard. |

## Commit guides

New in 0.6.0. See [Read a commit](../../guides/read-a-commit/).

| Command | What it does |
| --- | --- |
| `wisdom guide <commit>` | Have a model write that commit's guide now, and keep it in the commit's record. |
| `wisdom guide on\|off` | Whether a model writes a guide after each of your commits. Off by default; on by default in team mode. |

## Team mode

New in 0.6.0. See [Share with your team](../../guides/share-with-your-team/).

| Command | What it does |
| --- | --- |
| `wisdom team init` | Write `wisdom-team.json`. Commit it to turn team mode on. |
| `wisdom team hooks on\|off` | Install or remove Wisdom's three git hooks. `connect` and `init` install them in a team-mode repository. |
| `wisdom team push` | Send your sessions and commit records now, without a `git push`. |
| `wisdom team fetch` | Bring teammates' sessions here, read-only, and apply the deletion list. |
| `wisdom team delete <session>` | Remove a pushed session for everyone. Your own recording is kept. |
| `wisdom team prune` | Remove pushed sessions older than `retentionDays`. |
| `wisdom check --range <base>..<head>` | For CI: check each commit's guide, and that its sessions are on the remote. Exits with 1 when a commit needs attention. |

## Share a session

| Command | What it does |
| --- | --- |
| `wisdom share <session>...` | Write one file to send a teammate, after a secret check. |
| `wisdom import <file>` | Read a teammate's file here, read-only. |
| `wisdom export <session>` | Write a session as Markdown, after a secret check. |
| `wisdom clone <session>` | Carry a session on as a new one, in the same agent. |

## Background service and other

| Command | What it does |
| --- | --- |
| `wisdom daemon start\|stop\|status` | Control the background service. |
| `wisdom daemon run` | Run it in the foreground. |
| `wisdom mcp` | Serve the optional read-only MCP tool, `ledger`. |
| `wisdom --version` | Print the version. |

## Options

| Option | Used with | What it does |
| --- | --- | --- |
| `--cwd DIR` | any | Use the project at `DIR`. |
| `--data DIR` | any | Use the data folder `DIR` directly. Also `WISDOM_DATA_DIR`. |
| `--from N` | `glance`, `open` | Continue a long answer from line `N`. |
| `--at VERSION` | `glance`, `open` | Read at a fixed version. |
| `--plain` | `glance`, `open` | In a terminal, print the exact text agents read. |
| `--commit <commit>` | `glance` | Read a git commit instead of a session. |
| `--range <base>..<head>` | `check` | The commits to check, as git names a range. |
| `--remote NAME` | `team`, `check` | Use this remote instead of the one in `wisdom-team.json`. |
| `--from <session-id>` | `handoff` | The session to read. Default: the newest from another agent. |
| `--port N` | `daemon` | Use exactly this port. |
| `--no-dashboard` | `daemon` | Don't start the dashboard. |
| `--claude-bin FILE`, `--codex-bin FILE`, `--pi-entry FILE` | `track` | Use another installation of the agent. |
| `--setup-hooks` | `track codex` | Review Wisdom's hooks in `/hooks`, first time only. |
| `--trust-all-hooks` | `track codex` | Skip the review for **every** hook in that run. Only in repositories you trust. |
| `-- ARGUMENTS` | `track`, `handoff` | `track`: pass the rest to the agent. `handoff`: add it to the first prompt. |
| `--out FILE` | `share`, `export` | Where to save. Default `.wisdom/shared-out/`. `export --out -` prints it. |
| `--redact`, `--keep-secrets` | `share`, `export` | Redact or keep what the secret check finds, without asking. |
